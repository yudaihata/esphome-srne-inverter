## 1. 通信仕様概要
インバーター外部とのRS485通信プロトコル定義です。Modbus-RTUプロトコルに準拠しています。

### シリアルポート設定
* **ボーレート**: 9600 bps
* **データビット**: 8 bit / **パリティ**: なし / **ストップビット**: 1 bit (9600, n, 8, 1)

---

## 2. 【重要】実機検証に基づく通信ルール
公式マニュアルには記載がない、あるいは曖昧なものの、実動作で確認された重要な制限事項です。

### ルール①：ステータス読取もすべて「Function Code 03」を使用
一般的なModbus機器ではセンサー値（読み取り専用）に FC4 (Read Input Registers) を使用しますが、本機は**すべての読み出しが FC3 (Read Holding Registers) に統合**されています。
* **リクエスト**: センサー値（電圧、電流、発電量等）も **FC3** でリクエストしてください。
* **制限**: **FC4 を送信すると応答がなく、タイムアウト（Error 11等）が発生します。**

### ルール②：未定義アドレスを含む「一括読取」の禁止
通信効率化のために複数のレジスタをまとめて読み出す場合、リクエスト範囲内に1つでも「未定義（空き）アドレス」が含まれていると、正常なレジスタが含まれていてもエラーを返します。
* **挙動**: 指定範囲に空きがあると、**Illegal Data Address (02H)** エラーが発生します。
* **対策**: JSON等で定義されている「連続したアドレスブロック」ごとに、細かく分割してリクエストを投げる必要があります。

---

## 3. ファンクションコードとエラーコード
| コード | 機能 | 内容 |
| :--- | :--- | :--- |
| **03H** | Read multi-register | データの読み出し（設定・センサー共通） |
| **06H** | Write single register | 単一レジスタへの書き込み |
| **10H** | Write multi-register | 複数レジスタへの書き込み（最大32個） |

### 主な例外コード (Exception Codes)
* **02H (Illegal Data Address)**: 指定アドレスが存在しない、または読取範囲内に空きアドレスが含まれている。
* **0AH (Length error)**: 一度に読み書きするレジスタ数が32個を超えている。

## 4. 特殊なデータ処理・計算ルール

### バッテリー電圧設定の12V換算 (最重要)
設定エリア(P05等)のバッテリー電圧は、システムの定格に関わらず**すべて12Vシステム相当の値に換算**して送受信します。
* **計算式**: `通信値 = (設定したい電圧 / (定格電圧 / 12)) * 10`
* **例 (48Vシステムで57.6V設定)**: `57.6V / 4 = 14.4V` → `144 (0x0090)` を書き込む。

### 時刻設定値の計算
P05エリア等の時間指定レジスタ。
* **計算式**: `時 * 256 + 分`
* **例 (23時59分)**: `23 * 256 + 59 = 5947`

### 32ビットデータの格納順序
2レジスタ占有データは **リトルエンディアン (Small-endian)** です。
* `Address N`: 下位16ビット / `Address N+1`: 上位16ビット

---

## 5. 故障履歴の構造 (Group 10)
* 故障記録1件につき**16レジスタ**を占有。V1.96では32件分 (F800H〜F9FFH) 保持。
* 内部オフセット: `+0x00`: 故障コード, `+0x01〜0x03`: 発生時刻, `+0x04〜0x0F`: スナップショット。
